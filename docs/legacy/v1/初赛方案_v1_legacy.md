# 初赛方案

## 1. 摘要

本项目构建“黔址优选：两阶段社区商业智能选址推荐系统”，面向社区便利店与轻餐饮两类业态，采用“宏观公共数据约束 + 空间微观数据排序”的融合思路。官方宏观经济和就业数据用于刻画贵州整体市场环境、消费能力和就业客群背景；Geofabrik OSM 地理空间数据用于构造区域和 1km 评价网格的 POI、道路、土地利用等空间差异特征；模型通过便利店和轻餐饮两套权重方案，将宏观背景、空间可达性、商业配套、竞争压力和共生业态综合转化为多区域、多网格推荐结果。

## 2. 项目概述

商业选址需要多个可比较对象。当前官方 Excel 数据只能提供贵州整体背景，不能直接支撑区县、街道或网格差异。因此项目引入公开 OSM 地理空间数据，形成“两阶段选址推荐”：

1. 区域粗筛：基于 198 个 OSM 边界评价区域，计算 POI 密度、道路密度、土地利用占比等指标，选出更适合深入分析的区域。
2. 网格细筛：在入选区域内生成 1km 评价网格，重新聚合原始 POI、道路和土地利用几何，输出更细粒度的推荐网格。

当前结果定位为“优先考察区域”和“1km 评价网格”，不做真实门牌号级门店推荐。

## 3. 数据基础

### 3.1 官方公共数据

官方数据包括宏观经济指标、就业数据和字段结构说明。项目已生成官方数据清洗表、字段说明表和合理性报告。官方数据用于市场背景说明，不用于制造区域或网格差异。

### 3.2 OSM 地理空间数据

项目使用 Geofabrik 贵州 OSM GPKG，已完成 20 个图层盘点，并从 POI、交通、道路、土地利用、行政边界和地点图层中提取可用于选址的空间特征。

## 4. 指标与模型

当前评分指标包括：

- 交通可达性：道路密度、路口密度、公交站密度。
- 消费潜力：居住、商业、零售用地和商超配套。
- 共生业态：学校、医院、商场、办公、居住和商业配套。
- 竞争压力：餐饮、便利店、超市、商场等同业态密度，作为反向指标。
- 区域发展基础：商业、零售、办公、道路和产业空间基础。

便利店更看重居住消费基础、交通可达性和竞争压力；轻餐饮更看重交通可达性、共生业态和消费潜力。

## 5. 技术实现

系统流程为：

```text
官方背景处理 → OSM 图层盘点 → 区域粗筛 → 入选区域 1km 网格细筛 → 推荐解释 → 页面展示
```

核心输出：

- `outputs/results/region_stage/region_stage_score_result.csv`
- `outputs/results/region_stage/selected_regions_for_grid_stage.csv`
- `outputs/results/grid_stage/grid_stage_score_result.csv`

页面使用 Streamlit 展示区域推荐榜、入选区域和 1km 评价网格推荐榜。

## 6. 项目成效

当前版本已经完成从数据读取、空间特征聚合、指标构建、两阶段评分到页面展示的闭环。与只做整体评分相比，两阶段方案能输出多个可比较区域和多个 1km 评价网格，更符合商业选址需要。

## 7. 限制说明

- 缺失工商主体、企业信用、租金、实时客流和停车条件等数据，因此不进入当前评分。
- 就业地址文本不用于空间推断。
- OSM 标识不等同于官方行政区划代码。
- 当前为网格级推荐，不承诺具体门店盈利。
