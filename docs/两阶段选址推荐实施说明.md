# 两阶段选址推荐实施说明

## 1. 开发目标

项目主线为“两阶段空间选址推荐”：

1. 第一阶段使用 OSM 边界评价区域做区域级粗筛。
2. 第二阶段只在入选区域内生成 1km 评价网格，重新从 OSM 原始几何数据聚合 POI、道路和土地利用特征。

当前版本推荐的是“优先考察区域”和“1km 评价网格”，不是门牌号级推荐。

## 4. 执行入口

```bash
python src/official_pipeline.py
python src/osm_guizhou_pipeline.py --no-download
python src/two_stage_site_selection.py --top-n 5 --grid-size-m 1000
python src/report_generator.py
streamlit run src/app.py
```

手动指定区域：

```bash
python src/two_stage_site_selection.py --region-id 8316193 --grid-size-m 1000
```

## 5. 多次工作接续方式

每次接手先检查：

```powershell
Test-Path data\raw\official\就业表1.xlsx
Test-Path data\raw\osm_guizhou\guizhou.gpkg
Test-Path outputs\results\region_stage\region_stage_score_result.csv
Test-Path outputs\results\grid_stage\grid_stage_score_result.csv
```

若重新生成结果，先运行 OSM 管线，再运行两阶段推荐。

## 6. 约束

- 官方数据只作为贵州整体市场背景。
- 不从就业地址文本推断空间区域。
- 不把 OSM 标识写成官方行政区划代码。
- 不使用缺失的工商、信用、租金、实时客流、停车数据参与当前评分。
