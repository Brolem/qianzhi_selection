# 黔址优选商业计划书

> 项目名称：黔址优选  
> 项目定位：面向社区商业的 AI 选址辅助决策工作台  
> 适用赛道：贵州省人工智能创业大赛公共数据赛道  
> 当前版本：v2  
> 撰写日期：2026 年 6 月 16 日  

## 一、执行摘要

“黔址优选”是一套面向社区便利店、轻餐饮等社区商业业态的智能选址辅助系统。项目以贵阳市云岩区、南明区和观山湖区为试点，将官方公共数据、高德行政区划、高德 POI 样本、1km 空间网格、多因子评分、交互地图和结构化智能报告组织成一条可复现的商业选址分析链路。

项目当前已经形成可运行原型：覆盖 3 个目标区县、790 个空间评价网格、60 个 POI 样本网格、15 类 POI、8 项网格指标、2 套默认评分方案、六维自定义权重、区域市场诊断、地图洞察、智能报告和七页 Streamlit 工作台。系统默认离线流程可一键复现评分、地图和模板报告；联网能力只在用户显式刷新高德数据或调用 DeepSeek 报告时启用。

项目不承诺门牌号级铺位推荐，不预测真实租金、客流、营收或盈利。它解决的是前期调研阶段的核心问题：在数据口径不统一、人工踩点成本高、业态策略差异难表达的情况下，帮助用户快速筛选更值得优先调研的空间网格，并说明推荐原因、主要风险和数据边界。

商业化方向上，项目可从比赛原型演进为“社区商业选址智能工作台 + 区域诊断报告服务 + 政企数据应用解决方案”。短期面向连锁便利店、轻餐饮品牌、商业咨询团队和园区/社区运营方提供项目制服务；中期沉淀为 SaaS 化工作台；长期在合法授权数据基础上扩展更多城市、业态和经营校准模型。

## 二、赛事与政策背景

2026 年贵州省人工智能创业大赛以“智启黔程·创享未来”为主题，公开信息显示赛事目标包括集聚人工智能产业资源、挖掘优质创新项目、吸引创业人才，并推动创新链、产业链、应用链协同发展。高校宣讲信息也提到，参赛作品需提交可运行原型或演示视频及配套技术文档，并设置行业应用、公共数据、自由探索等方向。

本项目与赛事方向的匹配点在于：

1. 使用公共数据和开放位置服务构造可运行 AI 应用原型。
2. 面向实体商业经营和社区生活服务场景，而不是只做算法展示。
3. 输出可验证的工作台、地图、报告和运行摘要。
4. 通过明确数据边界降低模型误用风险，符合公共数据应用对可信、可解释和可追溯的要求。

社区商业本身也有明确政策背景。商务部等部门推动城市一刻钟便民生活圈建设，到 2030 年实现“百城万圈”目标，强调布局合理、业态齐全、服务优质、智慧高效。数字经济政策也要求推动商贸、物流、金融等服务业数字化转型，形成数据驱动的智能决策能力。

“黔址优选”将这些方向落到一个具体场景：用公共数据和 POI 数据辅助社区商业空间研判，让便利店、轻餐饮等小微业态的前期选址从“经验判断”走向“数据辅助 + 人工核验”。

## 三、行业痛点

### 3.1 人工经验难以覆盖大量空间单元

传统选址依赖人工踩点、门店经验、访谈和竞品观察。单个点位判断可以很细，但当需要同时比较多个区县、数百个空间单元和多种业态时，人工方法成本高、周期长、口径不一致。

### 3.2 区域平均值难以支撑门店初筛

区县级经济或就业数据只能说明宏观背景，不能直接判断同一区县内部不同街区和社区的差异。直接用区县平均分做门店选址，容易掩盖网格内部的交通、客群、商业氛围和竞争压力差异。

### 3.3 不同业态需要不同判断逻辑

便利店更关注社区刚需、居住客群、公共交通和周边生活配套；轻餐饮更关注办公客群、商业氛围、餐饮共生和到达便利性。若所有业态使用同一套权重和同一组竞品定义，推荐结果会失真。

### 3.4 推荐结果缺少解释和风险提示

很多选址工具只输出排名或热力图，难以解释“为什么推荐”“主要短板是什么”“竞争压力是否过高”。经营者仍需要将推荐结果翻译成可行动的调研清单。

### 3.5 AI 报告容易脱离真实证据

大模型可以快速生成商业分析文本，但如果没有程序化证据约束，容易出现数值复述错误、扩大数据含义、把样本结果写成经营保证等问题。

## 四、解决方案

“黔址优选”采用“空间网格 + POI 指标 + 六维评分 + 市场诊断 + 地图报告”的产品方案。

### 4.1 核心流程

```mermaid
flowchart LR
    A["确定区县范围"] --> B["生成 1km 评价网格"]
    B --> C["抽取 POI 样本网格"]
    C --> D["采集 15 类 POI"]
    D --> E["构造 8 项网格指标"]
    E --> F["选择业态方案或自定义权重"]
    F --> G["计算综合得分与排名"]
    G --> H["诊断市场阶段与竞争状态"]
    H --> I["地图洞察与智能报告"]
    I --> J["线下调研与经营决策"]
```

### 4.2 六维评分框架

系统使用六个正向维度进行评分：

| 维度 | 作用 |
|---|---|
| 交通可达性 | 反映公交站、地铁站、停车场等到达便利性代理 |
| 消费潜力 | 反映小区、超市、商场、学校、医院等生活消费场景代理 |
| 就业/办公客群代理 | 反映写字楼、商场、学校、餐饮等客群聚集代理 |
| 共生业态 | 反映目标业态周边有利配套 |
| 低竞争得分 | 由 `100 - 竞争压力` 得到，避免把竞品数量直接作为正向分 |
| 商业氛围 | 反映商场、餐饮、咖啡、茶饮、超市等商业活跃程度 |

社区便利店与轻餐饮共用通用框架，但使用不同的共生指标、竞争指标和默认权重。用户也可以基于社区零售型或餐饮服务型模板自定义六项权重，进行即时预览和正式保存。

### 4.3 当前原型结果

| 项目 | 当前结果 |
|---|---:|
| 目标区县 | 3 个 |
| 完整空间评价网格 | 790 个 |
| POI 样本网格 | 60 个 |
| 有 POI 活动网格 | 41 个 |
| 无 POI 活动网格 | 19 个 |
| POI 类别 | 15 类 |
| 网格级衍生指标 | 8 项 |
| 默认评分方案 | 社区便利店、轻餐饮 |
| 工作台页面 | 7 个 |

当前两类默认方案的全局第 1 网格均为 `grid_520103_000078`，所属区县为云岩区。社区便利店得分为 83.03，轻餐饮得分为 84.44。该结果只表示当前样本和权重下的相对优势，不代表具体铺位成功概率。

### 4.4 产品边界

系统输出的是优先考察网格、相对排名、指标分解、主要优势、主要风险、市场阶段、竞争状态、地图和报告。它不提供：

- 门牌号级铺位推荐。
- 租金、客流、营收和盈利预测。
- 商铺合同、产权、消防、环保和物业条件判断。
- 对未采集 POI 的空间网格填充分数。
- 用省级官方数据硬拆到 1km 网格的结论。

|---|---|---|
| 连锁便利店拓展团队 | 快速筛选社区网格和拓店方向 | 缩小踩点范围，形成统一比较口径 |

## 六、市场机会

### 6.1 政策驱动

一刻钟便民生活圈建设强调社区商业网点布局、业态补足和智慧化服务。对于地方政府、街道、社区和商业主体而言，如何低成本识别社区服务短板、招商方向和商业机会，是持续存在的现实需求。

### 6.2 商业主体数字化需求

便利店、餐饮、零售服务业普遍需要选址，但大量中小经营者缺少专业 GIS 团队和数据分析能力。即使大型连锁品牌具备内部模型，也需要面向新城市、新区县、新业态的快速初筛工具。

### 6.3 贵州场景价值

贵州正在发展人工智能和数据要素生态，贵阳贵安具备大数据产业基础，也具备社区商业、文旅消费、园区招商等多类空间决策场景。项目以贵阳典型区县为试点，后续可向更多区县和城市复制。

## 七、商业模式

### 7.1 当前阶段定位

当前项目处于比赛原型和早期验证阶段，尚未形成真实营收。商业计划中的收入路径属于产品化规划，不是当前已发生收入。

### 7.2 收入来源规划

| 模式 | 面向对象 | 交付内容 | 适用阶段 |
|---|---|---|---|
| 项目制分析服务 | 品牌拓展、咨询团队、园区运营方 | 指定区域数据处理、评分、地图和报告 | 0 到 6 个月 |
| SaaS 订阅 | 连锁品牌、咨询公司、运营机构 | 多区域工作台、方案管理、报告导出 | 6 到 18 个月 |
| 私有化部署 | 政企客户、园区集团、商业咨询机构 | 本地部署、数据接入、权限和安全配置 | 12 个月后 |
| 数据与模型扩展服务 | 已有客户 | 新城市、新业态、新数据源、新指标模板 | 持续 |
| 培训与咨询 | 高校、赛事团队、商业培训机构 | 公共数据应用、GIS 分析、AI 报告课程 | 持续 |

以下为比赛版规划口径，落地前需根据客户规模、数据授权、服务范围和交付周期重新报价：

| 产品包 | 建议形态 | 规划定价口径 |
|---|---|---|
| 单区域诊断报告 | 单个区县或商圈，含地图和推荐清单 | 按项目收取服务费 |
| 城市工作台基础版 | 固定城市、固定业态、有限账号 | 按年订阅 |
| 专业版 | 多业态、自定义权重、批量报告、结果导出 | 按年订阅 + 使用量 |

## 八、竞争分析

| 类型 | 典型能力 | 局限 | 黔址优选差异 |
|---|---|---|---|
| 通用地图与商圈平台 | 地图、POI、商户搜索、热力展示 | 更偏查询展示，评分逻辑和权重不可控 | 将 POI 转化为可解释六维评分和报告 |
| 大型连锁内部选址系统 | 数据丰富、贴近经营结果 | 封闭、成本高，中小主体难使用 | 面向公共数据和开放位置服务构建轻量原型 |
| 商业咨询人工报告 | 经验丰富、可深度访谈 | 周期长、成本高、复现性弱 | 自动生成初筛清单和结构化证据 |
| GIS 桌面分析 | 空间能力强 | 使用门槛高，业务解释弱 | 封装为七页工作台和面向经营者的语言 |
| 通用大模型分析 | 文本生成快 | 容易脱离真实数据 | 大模型只在证据白名单内生成报告素材 |

项目优势不是“替代所有选址工作”，而是将前期筛选和证据整理做得更快、更透明、更可复现。

## 九、技术与产品壁垒

1. **数据职责清晰**：官方数据只用于省级背景，高德边界用于空间范围，POI 样本用于网格指标，不混用数据层级。
2. **可解释评分**：从 15 类 POI 到 8 项指标，再到六维权重和排名，每一步可复算。
3. **业态模板与权重分离**：便利店和轻餐饮可共享框架，又保持不同共生和竞争逻辑。
4. **自定义权重闭环**：用户可以即时预览不同策略下的排名变化，并保存正式方案。
5. **地图与报告联动**：同一评分结果进入表格、地图、智能报告，避免多套口径。
6. **受约束 AI 报告**：DeepSeek 不直接改分、不自行生成数值，报告由程序回填真实字段。
7. **工程可复现**：默认离线一键运行、缓存、原子输出、测试和文档形成交付闭环。

## 十、推广策略

### 10.1 比赛阶段

- 以“AI + 公共数据 + 社区商业选址”为主叙事。
- 展示七页工作台、Top 网格、地图、智能报告和自定义权重。
- 强调可运行原型、真实数据边界和可复现流程。
- 使用商业计划书、架构说明和 PPT 形成一致材料。

### 10.2 试点阶段

- 选择 1 到 2 个便利店或轻餐饮品牌进行联合试用。
- 用同一城市不同区县验证“推荐网格是否缩小调研范围”。
- 记录用户在线下核验中对指标、权重和报告的反馈。
- 补充客户真实关注字段，如租金区间、面积、门头可见性、外卖覆盖和时段客流。

### 10.3 产品化阶段

- 扩展贵阳市更多区县。
- 扩展药店、生鲜、银行网点、托育、养老服务等业态，但必须先补充专属数据和指标模板。
- 增加团队账号、项目管理、报告批量导出、权限控制和部署脚本。
- 建立客户案例和标准实施流程。

## 十二、财务规划

### 12.1 成本结构

| 成本项 | 内容 |
|---|---|
| 数据与 API 成本 | 高德 Web 服务、地图 JS API、后续授权数据源 |
| 算力与部署成本 | 云服务器、对象存储、日志监控、备份 |
| 研发成本 | 数据管线、模型、地图、报告、前端和测试 |
| 业务成本 | 调研、客户沟通、方案设计、售前演示 |
| 合规成本 | 数据授权、隐私审查、合同和安全文档 |

### 12.2 收入测算口径

当前没有真实销售数据，因此不写已实现收入。后续财务模型建议按三类收入分别测算：

1. 项目制报告：按区域、业态、数据深度和报告数量计费。
2. SaaS 订阅：按账号、城市包、业态包和导出额度计费。
3. 私有化部署：按实施费、年度维护费和定制开发费计费。

比赛答辩阶段可使用“保守、中性、积极”三档情景测算，但每一档都应明确客户数量、单价、续费率、API 成本和人力成本假设，不能把规划测算写成已发生经营成果。

## 十三、风险与控制

| 风险 | 表现 | 控制措施 |
|---|---|---|
| 数据覆盖风险 | 当前 POI 只覆盖 60 个样本网格 | 明确样本边界，后续扩展采集范围和多源核验 |
| 代理指标风险 | POI 不能替代真实客流、租金和消费数据 | 文档、页面和报告持续提示数据含义 |
| 业态扩展风险 | 仅改名称无法支撑新业态 | 新业态必须新增数据、共生指标和竞争指标 |
| AI 生成风险 | 报告可能扩大结论 | 使用证据白名单、结构化 JSON 和程序回填 |
| 商业转化风险 | 客户可能只把系统当展示工具 | 通过试点验证“缩小调研范围”的实际价值 |
| 合规风险 | 第三方 API 和客户数据授权不清 | 明确数据来源、授权边界和凭据管理 |
| 决策误用风险 | 用户把网格推荐当最终开店保证 | 强制加入线下核验清单和不承诺盈利说明 |

## 十四、团队分工建议

| 商业与运营 | 客户画像、商业模式、试点合作和财务测算 |

## 十五、社会价值

1. 帮助小微经营者降低前期调研门槛。
2. 帮助连锁品牌更系统地观察社区商业机会。
3. 帮助园区和社区运营方识别业态补足方向。
4. 为便民生活圈建设提供数据辅助视角。
5. 展示公共数据、GIS 和人工智能结合的可复现工程样例。
6. 在明确边界的前提下推动 AI 应用于实体经济决策。

## 十六、结论

“黔址优选”的商业价值不在于宣称替代线下选址，而在于把前期商业调研中最耗时、最容易口径不一致的部分标准化：统一空间网格、统一 POI 口径、统一指标构造、统一评分和统一报告。它让经营者、咨询人员和政府/园区运营方能够更快得到优先调研清单，并带着明确问题进入现场核验。

当前 v2 原型已经具备比赛展示所需的可运行性、可解释性和工程完整度。下一步商业化重点不是增加更多口号，而是围绕真实客户试点补齐数据授权、调研闭环、权限部署和付费场景。
