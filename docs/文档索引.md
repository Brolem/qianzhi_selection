# 文档索引

## 核心文档

当前 `docs/` 只保留支撑运行、交付和评审的核心文档。过程性方案、重复说明和旧商业计划书已移除，避免同一内容多处维护。

| 文档 | 用途 |
|---|---|
| `competition_submission/项目计划书.md` | 比赛提交用项目计划书，覆盖项目背景、目标、产品方案、技术路线、实施计划、应用场景、创新点、风险和验收 |
| `competition_submission/架构说明.md` | 比赛提交用架构说明，覆盖数据层、管线层、模型层、报告层和前端层 |
| `网格推荐全流程与评分计算说明.md` | 评分计算、指标工程、排名、推荐等级、区域诊断和真实精算案例 |
| `项目结构说明.md` | 当前源码、数据、输出、测试和 v1 隔离边界 |
| `最终交付清单.md` | 一键运行输入、生成文件、页面、密钥和交付前检查 |
| `5分钟演示脚本.md` | 比赛答辩的五分钟工作台演示顺序与讲解要点 |
| `../黔址优选_Codex多步执行指令.md` | v2 总控源文档，保留 Step 0 到 Step 18 的执行依据和历史决策 |

## 比赛提交材料

比赛正式提交材料位于：

```text
docs/competition_submission/
```

该目录只保留两个文件：

1. `项目计划书.md`
2. `架构说明.md`

如需提交材料，优先使用该目录，不再从根级 `docs/` 拼接旧方案文档。

## 历史状态文档

迁移过程记录位于：

```text
docs/history/
```

`history/迁移前项目状态.md` 记录结构分离前的真实仓库状态，正文中的旧路径不作为当前入口。
