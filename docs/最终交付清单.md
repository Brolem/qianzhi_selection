# 最终交付清单

## 一、运行环境

- Python：`3.13.12`。
- 依赖：使用根目录 `requirements.txt` 中的锁定版本。
- 默认命令：`python scripts/run_pipeline.py`。
- 工作台命令：`python scripts/run_pipeline.py --serve` 或 `streamlit run src/app.py`。
- 项目结构：见 `docs/项目结构说明.md`。
- 系统架构：见 `docs/系统架构说明.md`，当前主线按数据层、管线层、模型层、报告层和前端层组织。

## 二、仓库输入

默认离线复现依赖以下已跟踪文件：

- `data/processed/target_districts.csv`
- `data/processed/target_district_boundaries.geojson`
- `data/processed/candidate_grids.csv`
- `data/processed/grid_poi_raw.csv`
- `data/processed/grid_poi_counts.csv`
- `data/processed/official/macro_clean.csv`
- `data/processed/official/employment_clean.csv`

在线刷新官方数据时，`data/raw/official/` 必须包含六个现有 Excel。在线刷新高德数据时必须配置 `AMAP_KEY`。

## 五、五层架构交付检查

| 层级 | 检查项 |
|---|---|
| 数据层 | `data/processed/`、`outputs/results/`、`outputs/figures/`、`outputs/reports/` 中的当前主线文件可由默认流程复现 |
| 管线层 | `src/pipeline/` 能按需刷新官方数据、高德区县、1km 网格和 POI 样本 |
| 模型层 | `src/modeling/` 能生成 8 项指标、两类默认评分、自定义权重结果和区域市场诊断 |
| 报告层 | `src/presentation/` 能生成地图 HTML、模板报告和 DeepSeek 结构化报告 |
| 前端层 | `src/app.py` 与 `src/web/` 能展示七页工作台，并复用同一评分方案目录 |

## 六、交付前检查

- 一键运行摘要显示 3 个区县、790 个空间网格、60 个 POI 样本网格、41 个活跃网格和 19 个无活动网格。
- 两类默认评分均有完整排名、Top 10、优势、风险和推荐等级。
- 两张地图存在且可打开。
- 两份 Top 1 报告均有 11 个章节。
- 自定义权重预览能够改变排名；正式保存后可被地图和报告页识别。
- 地图页优先使用高德 JS API；凭据缺失时兼容地图可正常显示。
- 智能报告页只有点击按钮后才调用 DeepSeek，并显示生成状态。
- 仓库文件、日志、截图和文档不包含任何 API Key 明文。
- 项目只输出优先考察网格，不解释为具体门店地址或经营收益保证。
- 当前主线不导入 `src/legacy/v1/`，旧版只读写 `data/legacy/v1/` 和 `outputs/legacy/v1/`。

## 七、密钥清单

- `AMAP_KEY`：高德行政区划和 POI Web 服务。
- `AMAP_JS_KEY`：高德地图 JS API。
- `AMAP_JS_SECURITY_CODE`：高德地图 JS API 安全密钥。
- `DEEPSEEK_API_KEY`：智能报告。

密钥均使用环境变量配置，不纳入项目文件。
