# 黔址优选：城市社区商业价值洞察与智能选址平台项目计划书

> 项目名称：黔址优选：城市社区商业价值洞察与智能选址平台  
> 项目方向：公共数据赛道 / 社区商业智能选址  
> 项目版本：v2 当前主线  
> 提交材料类型：项目计划书  
> 编制日期：2026 年 6 月 17 日  

## 一、执行摘要

“黔址优选：城市社区商业价值洞察与智能选址平台”是一套面向社区便利店、轻餐饮等社区商业业态的智能选址辅助工作台。项目以贵阳市云岩区、南明区和观山湖区为试点，将官方公共数据、高德行政区划、高德 POI 样本、1km 空间评价网格、多因子评分、区域市场诊断、地图洞察和结构化智能报告组织为一条可复现的商业选址分析链路。

当前原型已经形成从数据输入到工作台展示的闭环：覆盖 3 个目标区县、790 个空间评价网格、60 个 POI 样本网格、15 类 POI、8 项网格指标、2 套默认评分方案、六维自定义权重、区域市场诊断、地图洞察、智能报告和七页 Streamlit 工作台。默认一键流程可以离线复现指标、评分、地图和模板报告；高德数据刷新和 DeepSeek 报告均通过显式参数或页面按钮触发。

项目解决的是社区商业前期调研中的初筛问题：在无法一次性掌握租金、真实客流、门店合同和现场条件的情况下，先用统一数据口径筛选值得优先调研的空间网格，解释推荐依据和主要风险，帮助经营者、品牌拓展团队、园区和社区运营方缩短调研周期、统一比较标准。

本项目不输出门牌号级铺位推荐，不预测真实租金、客流、营收或盈利，不把省级公共数据硬拆到 1km 网格。系统定位是“数据辅助决策工具”，不是替代线下尽调和经营判断的自动开店模型。

## 二、项目背景与赛事契合

公开报道显示，2026 年贵州省人工智能创业大赛于 2026 年 4 月 23 日在贵阳启动，赛事面向传统产业数字化转型、企业生产经营痛点、民生服务提质增效等现实需求征集人工智能解决方案。赛事目标包括集聚人工智能产业资源、挖掘优质创新项目、吸引创业人才，并推动创新链、产业链、应用链协同发展。[^1]

高校宣讲信息显示，该赛事设行业应用赛道、公共数据赛道、自由探索赛道三大方向，并要求参赛作品提交可运行原型或演示视频及配套技术文档。[^2] “黔址优选：城市社区商业价值洞察与智能选址平台”采用公共数据、位置服务、GIS 网格、可解释评分和大模型报告形成可运行原型，与公共数据赛道和民生服务提质场景具备直接对应关系。

社区商业是城市生活服务体系的重要组成部分。新华社关于一刻钟便民生活圈建设的报道指出，便民生活圈以社区居民为服务对象，让居民在步行 15 分钟范围内获得购物、餐饮、家政、维修等基本生活服务，并提升文化、休闲、康养、托育等品质服务。报道同时提到，各地正在利用大数据、互联网、云计算、人工智能等技术优化社区商业管理和服务。[^3]

《“十四五”数字经济发展规划》提出引导企业强化数字化思维、推动研发设计、生产加工、经营管理、销售服务等业务数字化转型，并强调大力发展数字商务，全面加快商贸、物流、金融等服务业数字化转型，形成数据驱动的智能决策能力。[^4] 本项目将这些方向落到社区商业选址场景：用公共数据说明区域背景，用开放位置数据刻画空间环境，用模型评分形成可比较的网格推荐，用智能报告降低结果解释成本。

## 三、问题定义与建设必要性

传统商业选址依赖经验、踩点、访谈和人工竞品观察，面对多个区县和数百个空间单元时难以快速覆盖。区县级平均指标又过于粗糙，无法解释同一区县内不同社区、道路和商圈的差异。对于小微创业者、社区商业运营方和连锁品牌拓展团队而言，前期筛选阶段尤其需要一套低成本、可解释、可复现的初筛工具。

本项目重点解决四类问题：

1. **空间粒度问题**：将区县背景约束细化为 1km 网格评价对象。
2. **数据口径问题**：把 POI 统计、评分指标和推荐解释统一到同一套网格口径。
3. **业态差异问题**：支持社区便利店、轻餐饮和自定义权重方案，体现不同业态对消费潜力、就业客群、共生业态和竞争压力的偏好差异。
4. **解释成本问题**：用地图、诊断标签和智能报告解释推荐结果，降低非技术用户理解门槛。

## 五、产品方案

项目最终形态是一个可运行的 Streamlit 工作台，包含项目总览、数据底座、区域对比、网格推荐、地图洞察、智能报告和项目说明七个页面。

核心功能包括：

- **数据总览**：展示目标区县、空间网格、POI 类别、活跃推荐网格和主题 POI 摘要。
- **区域对比**：对比三区 POI 原始数量、活跃网格平均得分和区县差异。
- **网格推荐**：展示默认方案和自定义方案下的全部有效排名，支持区县、市场阶段和竞争状态筛选。
- **自定义权重**：用户可用六项百分比权重构造新业态方案，前端即时调用后端评分接口。
- **区域诊断**：识别市场空白型、待培育型、成熟商圈型、一般观察型和过度竞争预警。
- **地图洞察**：以高德地图展示 790 个网格的覆盖状态、评分色阶和 Top 标记。
- **智能报告**：为指定评分方案和网格生成 11 章结构化选址报告，大模型不可用时提供模板兜底。

## 六、技术路线

### 6.1 数据路线

1. 官方公共数据用于说明贵州省级市场背景，不拆分到区县或网格。
2. 高德行政区划 API 获取三区区县边界和中心点。
3. 基于区县边界生成 1km 空间评价网格。
4. 对每区 20 个空间分散网格采集 15 类高德 POI 样本。
5. 将 POI 统计与网格属性合并为评分输入。

高德行政区域查询文档明确说明街道级不能返回边界数据，因此项目不把街道边界作为评分对象，而是在区县边界内构建统一 1km 网格。[^5] 高德 POI 2.0 支持关键字、分类编码、周边搜索和多边形搜索，但接口不等同于全量设施数据库，因此项目将 POI 数据定位为统一口径样本，而不是完整设施总量。[^6]

### 6.2 模型路线

模型采用“POI 计数 - 指标工程 - 六维评分 - 区域诊断 - 推荐解释”的路线：

1. 对 POI 计数字段执行 `log1p` 缩放。
2. 在 60 个样本网格内做全局 0-100 Min-Max 归一化。
3. 生成交通可达性、消费潜力、就业客群代理、商业氛围、共生业态和竞争压力相关指标。
4. 对社区便利店和轻餐饮分别设置默认均衡差异化权重。
5. 支持用户自定义六项权重，实时生成新的评分、排名和解释。
6. 使用三分位阈值生成区域市场诊断标签。

### 6.3 报告路线

报告层包括地图和文本两类成果。地图直接使用高德 JS API 展示 GCJ-02 空间网格，缺少凭据时回退到兼容地图。文本报告采用结构化提示词和程序校验，要求报告固定包含 11 个章节，并严格说明数据来源和限制。

## 八、应用场景

1. **小微创业者选址初筛**：快速识别适合优先走访的社区网格。
2. **连锁品牌拓展**：用统一口径比较不同区县和网格的机会与风险。
3. **社区商业规划**：辅助识别市场空白、待培育区域和过度竞争区域。
4. **园区及街区运营**：为招商、业态组合和服务补短板提供空间参考。
5. **比赛与教学演示**：展示公共数据、位置服务、GIS 和大模型在商业决策中的融合方式。

## 九、创新点

1. **从区县背景转向网格评分**：区县只作为空间约束，真正评分对象是 1km 网格。
2. **评分与诊断并行**：系统不仅推荐 Top 网格，还识别市场空白和过度竞争区域。
3. **自定义权重直连后端模型**：前端输入权重后直接调用评分接口，不靠静态展示模拟。
4. **地图与报告同源解释**：地图弹窗、推荐表和智能报告均复用同一套评分字段和诊断标签。
5. **默认离线复现**：交付流程不依赖实时 API，便于比赛演示和评审复核。

## 十一、风险与应对

| 风险 | 表现 | 应对 |
|---|---|---|
| POI 样本不等于全量设施 | 部分网格或类别可能被低估 | 明确样本边界，使用统一口径做相对比较 |
| 缺少真实客流和租金 | 无法直接预测营收和盈利 | 把结果定位为优先调研网格，不输出经营收益保证 |
| API 额度和网络波动 | 在线刷新可能失败 | 默认离线复现，在线刷新显式启用并使用缓存 |
| 大模型输出不稳定 | 可能产生无依据表达 | 程序校验、模板兜底、固定数据边界 |
| 跨城市复制需要调整 | 不同城市 POI 分布和商业结构不同 | 保留配置化区县、业态和权重方案 |
