# 赛题需求与开发差距分析

## 1. 开发目标

赛题目标是商业智能选址。选址必须有多个地点或评价区域参与评分推荐，不能停留在整体展示。因此当前项目目标明确为：

```text
区域粗筛 + 1km 评价网格细筛 + 多业态评分推荐 + 推荐理由与风险提示
```

官方不再提供其他数据。缺失的工商、信用、租金、实时客流、停车等指标暂不纳入当前评分；如后续自行获取可靠外部数据，再作为扩展接入。

## 2. 赛题要求重整

当前版本必做：

- 区域商业价值评估。
- 多因子评分。
- 便利店和轻餐饮差异化权重。
- 多个推荐区域和多个评价网格的排序。
- 推荐理由、风险提示和报告说明。

暂不纳入当前评分：

- 工商主体数据。
- 企业信用数据。
- 流动人口与实时客流。
- 租金行情。
- 停车便利性。
- 用户上传门店经营数据。

## 3. 现有数据基础

官方数据：

- 宏观经济数据和就业数据已完成读取。
- 官方数据只能作为贵州整体市场背景。
- 就业数据没有已确认的区域字段，不从就业地址文本推断空间区域。

OSM 空间数据：

- 已获取 `data/raw/osm_guizhou/guizhou.gpkg`。
- 已完成 20 个图层盘点。
- 已生成 198 个 OSM 边界评价区域的 POI、道路、土地利用特征。
- 已在入选区域内生成 1km 评价网格细筛结果。

## 4. 当前已完成

- 官方数据读取、字段说明和合理性报告。
- OSM 贵州数据接入和图层盘点。
- 区域粗筛评分输入和评分结果。
- 入选区域列表。
- 入选区域内 1km 评价网格空间特征。
- 网格级便利店和轻餐饮推荐结果。
- Streamlit 两阶段展示入口。

## 5. 仍未达到

- 尚未做地图可视化。
- 尚未提供用户自定义权重。
- 尚未接入工商、信用、租金、实时客流、停车等外部数据。
- 尚未形成门牌号级推荐。

## 6. 开发难点

- 官方数据粒度与空间推荐粒度不一致。
- OSM 边界面积差异较大，区域粗筛必须使用密度和占比指标。
- 1km 网格必须从原始几何重新聚合，不能拆分已有区域聚合表。
- 空间叠加计算可能随入选区域数量增加而变慢。
- 缺失指标必须剔除或作为扩展，不能编造。

## 7. 下一步优先级

P0：

- 验证两阶段推荐结果的业务合理性。
- 检查前 5 个入选区域的网格推荐榜。
- 保持页面主入口读取两阶段结果。

P1：

- 增加地图可视化。
- 增加权重配置界面。
- 生成面向答辩的推荐报告。

P2：

- 仅在取得可靠外部数据后，再接入工商、信用、租金、实时客流、停车等指标。
