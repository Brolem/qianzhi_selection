# 5 分钟演示脚本

## 0:00–0:35 传统选址痛点

打开“项目总览”。

讲解要点：

- 社区商业选址需要同时比较交通、客群、业态协同、竞争和商业氛围。
- 传统人工调研难以在统一口径下快速比较大量空间单元。
- 本项目输出的是优先考察的 1km 评价网格，不是具体门店地址。

## 0:35–1:10 数据底座

进入“数据底座”。

讲解要点：

- 官方宏观和就业数据用于贵州省级市场背景说明。
- 高德行政区划用于三区边界，高德 POI 样本用于网格指标。
- 当前有 790 个空间网格，其中 60 个网格完成统一口径 POI 采集。
- 数据坐标保持 GCJ-02，与高德地图同源展示。

## 1:10–2:15 网格推荐

进入“网格推荐”，先选择默认社区便利店。

讲解要点：

- 展示全局 Top 10、区县 Top 5、推荐等级、主要优势和主要风险。
- 便利店与轻餐饮采用不同权重和不同共生、竞争指标。
- 19 个无 POI 活动网格保留审计状态，但不进入推荐排名。

切换到默认轻餐饮，说明两种业态的排序差异。

## 2:15–2:55 自定义权重

选择“新建自定义方案”。

讲解要点：

- 用户可设置交通、消费、就业客群代理、共生、竞争和商业氛围六项权重。
- 页面实时显示已分配和剩余权重，可使用预设或自动归一。
- 前端直接调用同一评分接口即时重算，不复制另一套评分逻辑。

调整一项权重并展示 Top 10 变化，不必保存临时演示方案。

## 2:55–3:55 地图洞察

进入“地图洞察”。

讲解要点：

- 地图展示全部 790 个空间网格，并区分未采集、无活动和活跃评分网格。
- 活跃网格使用相对评分色阶，全局 Top 10 使用编号圆标。
- 悬停查看摘要，点击查看六维指标、优势、风险和推荐等级。
- 高德 JS API 直接使用 GCJ-02；必要时可切换兼容地图。

## 3:55–4:40 智能报告

进入“智能报告”，选择便利店排名第 1 的活跃网格。

讲解要点：

- 点击后才调用 DeepSeek，页面显示生成状态。
- 模型只生成结构化分析素材；程序校验证据并写入真实分数、排名和权重。
- 报告固定为 11 个章节，可下载 Markdown。
- API 不可用时会明确显示错误，并允许用户主动生成规则模板报告。

演示时可使用已生成报告，避免现场网络波动。

## 4:40–5:00 项目边界与结论

总结：

- 项目形成“公共数据背景、POI 样本、网格评分、地图解释、智能报告”的闭环。
- 结果支持统一口径下的相对比较，不代表完整设施总量。
- 当前未接入真实租金、实时客流、营收和门店经营流水。
- 推荐结果用于缩小实地调研范围，最终决策仍需现场核验。
